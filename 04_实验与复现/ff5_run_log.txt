【Gap 清单】论文做法 → 留出的口子 → 可写成创新点的改写方向
================================================================================

  Gap 1
    论文做法 → 市值口径用【流通市值】加权，Size 与 B/M 分母均为流通市值
    留出口子 → 流通市值只覆盖部分股本；国有控股比例高时与总市值排序差异大，小盘股被系统性错分。LSY(2019) 用总市值构造
    改写方向 → 做【流通市值 vs 总市值】双口径对照，量化 SMB 载荷错分对「股改后规模效应增强」这一结论的贡献度

  Gap 2
    论文做法 → 直接照搬 FF(2015a) 分组流程，采用【全体 A 股分位点】
    留出口子 → 未剔除最小 30% 市值（壳价值污染）。借壳上市的壳期权价值进入小盘股收益，且 83% 的借壳标的来自最小 30%
    改写方向 → 剔除最小 30% 或以「高壳概率」筛选（Li & Rao 2022）后重估，检验「CMA 冗余」结论是否翻转

  Gap 3
    论文做法 → OP 用「营业利润 / 股东权益合计」替代 FF 的「营业利润 / 账面权益」
    留出口子 → 原文以中美会计准则差异为由直接替换，但【未论证两种口径的等价性】
    改写方向 → 构造两套 OP 并做等价性检验（相关系数 + 排序一致性 + 因子收益对比），量化口径替换带来的因子载荷漂移

  Gap 4
    论文做法 → B/M 作为唯一价值变量，未与竞争性估值指标赛马
    留出口子 → LSY(2019) 的 Fama-MacBeth 赛马表明，中国市场 E/P 吸收 B/M 的全部价值效应；原文照搬美国结论选用 B/M
    改写方向 → 以 E/P 重建 HML，做 B/M vs E/P 赛马，检验 HML 冗余性与「股改后市场趋于有效」结论的稳健性

  Gap 5
    论文做法 → 股改断点使用单一已知点 Chow 检验（2007-06）
    留出口子 → 只有一次结构化检验，无法识别 2017 注册制等后续断点，也无法给出断点位置的置信区间
    改写方向 → 单一 Chow → 多重未知断点（Bai-Perron 或顺序检验），输出断点个数、位置与置信区间

  Gap 6
    论文做法 → MOM 因子按 FF(2016) 方向构建（高历史收益减低历史收益）
    留出口子 → 文章已发现中国市场是【反转】效应，却仍沿用动量方向的因子；截距显著为负，正说明因子方向与实际效应相反
    改写方向 → 显式构建反转方向因子，并检验换手率 / 情绪（PMO）能否解释股改后反转效应

  Gap 7
    论文做法 → 模型评估以月度频率、GRS + 截距项四指标为主
    留出口子 → 未考虑交易成本；未做多重检验校正（同一数据集上数百个因子的检验）
    改写方向 → 加入换手率与成本约束后的净 alpha 排序；用 Harvey-Liu(2020) 双重自举做多重检验校正

  Gap 8
    论文做法 → 作者在结论中交棒：FF5 与 FF6 在某些分组下仍无法通过 GRS
    留出口子 → 未回答「是哪些分组、为什么失败、缺哪个因子」
    改写方向 → 定位 GRS 失败的分组切片，反推缺失因子的经济学属性，构造候选新因子并做样本外验证
