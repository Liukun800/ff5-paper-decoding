# SOP 04 · 实验与复现说明

## 文件

- `ff5_3d_repro.py`：三维结构法"跑通灵魂代码"环节的复现骨架，端到端串联 **数据合成 → 2×3 分组因子构建 → 25 个规格化组合 → GRS 检验 → 邹至庄断点检验（已知断点 + 未知断点扫描）**。
- `ff5_run_log.txt`：一次完整运行的日志。

## 运行

```bash
# Python 3.11+；依赖 numpy / pandas / scipy
pip install numpy pandas scipy
python ff5_3d_repro.py
```

## 重要声明

1. 脚本内置 `make_panel()` **合成数据生成器**（DGP 中嵌入 2005-06 股权分置改革断点：股改前市场风险主导、RMW/CMA 载荷为零；股改后载荷开启），用于验证方法链路正确性——**日志中的数值不可与原文实证结果直接比较**。
2. 接入真实数据：把 `make_panel()` 替换为 Wind/CSMAR 导出面板，保持列名 `date / code / size / bm / ep / op / inv / ret` 不变，其余链路无需改动。
3. 方法论教训（复现时踩过的坑）：断点检验必须施加在**因子载荷回归**上；对组合均值做 Chow 检验功效不足（F≈1.1），对载荷回归并按 Fisher 法合并 25 个 panel 的 p 值后，检验功效充足且扫描能独立命中股改分界。
