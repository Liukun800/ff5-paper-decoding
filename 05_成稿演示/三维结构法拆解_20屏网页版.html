裂缝三 · 范式挑战

LSY(2019, JFE) 直接否掉「照搬」的合法性

中国 IPO 严格管制 → 借壳上市 → 小市值股票的价格里含壳期权价值。 实证：83% 的借壳标的来自最小 30% 的股票， 这部分股票的市值约 30% 反映壳价值。

另一个打击：中国市场的价值效应由 E/P 承载，B/M 被完全吸收。

本文的口径是：全体 A 股分位点 + 流通市值 + B/M（原文 p.194 及脚注）。 而 LSY 的三条修正正好打在这三处：剔除最小 30%、改用总市值、改用 E/P。

这就是「体系外裂缝」——不是让你去挑作者的错，是让你发现： 他的结论建立在一套已被后续文献质疑的口径上，而这套口径下没人重跑过分期检验。

def grs_stat(alphas, resid, factors):
    """H0 = 所有截距项联合为 0，服从 F(N, T-N-L)"""
    Tn, N = resid.shape
    L = factors.shape[1]
    a = alphas.reshape(-1, 1)
    sigma = resid.T @ resid / Tn        # 残差协方差
    fm = factors.values - factors.values.mean(axis=0)
    omega = fm.T @ fm / Tn              # 因子协方差
    mu = factors.values.mean(axis=0).reshape(-1, 1)
    num = (a.T @ np.linalg.pinv(sigma) @ a)[0, 0]
    den = 1 + (mu.T @ np.linalg.pinv(omega) @ mu)[0, 0]
    g = ((Tn - N - L) / N) * num / den
    return g, 1 - stats.f.cdf(g, N, Tn - N - L)
