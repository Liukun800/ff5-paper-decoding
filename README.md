## 核心发现速览

- **裂缝一（体系内）**：本文表 3（P196）显示 CMA（投资因子）经 GRS 检验被判冗余——美国市场是 HML 冗余，中国市场冗余的是另一根支柱。
- **裂缝二（同市场相反）**：高春亭和周孝华（2016）认为五因子优于三因子、赵胜民等（2016）认为盈利与投资因子无益、Guo et al.（2017）认为投资因子冗余——三篇结论相反，且**都只做全样本**。
- **裂缝三（体系外）**：Liu, Stambaugh & Yuan（2019, JFE）指出中国 IPO 管制导致壳价值污染（83% 借壳标的来自最小 30% 市值组），且中国市场价值效应由 E/P 承载、B/M 被完全吸收——本文口径恰在两处受影响。
- **复现要点**：断点检验必须对**因子载荷回归**做邹至庄检验（对均值做检验功效不足），25 个 panel 用 Fisher 法合并 p 值。

## 复现说明

```bash
# 环境：Python 3.11+，numpy / pandas / scipy
python 04_实验与复现/ff5_3d_repro.py
```

> ⚠️ 脚本使用**合成数据**跑通方法链路（DGP 内置 2005 年股权分置改革断点），数值不可与原文直接比较；将 `make_panel()` 替换为 Wind/CSMAR 真实面板（列名 `date/code/size/bm/ep/op/inv/ret`）即可全链路复跑。详见 `04_实验与复现/ff5_run_log.txt`。
